# Implementing Redis From Scratch

C will be used mostly but with minimal C++ like for creating key-value pair

## Concepts learnt so far
- epoll
- how to create event loop using epoll

## How to comiple and run
- For Compiling
```bash
make redis_server
make redis_client
```
- For Running
```bash
./redis_server
./redis_client
```
- Now delete all the executable files
```bash
make clean
```
